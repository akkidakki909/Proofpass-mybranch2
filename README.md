# ProofPass

ProofPass web application and verification system.

## Project Structure

- `frontend/`: ProofPass user interface, styles, and client scripts.
  - `frontend/index.html`: Main web application view.
  - `frontend/privacy.html`: Privacy policy.
  - `frontend/terms.html`: Terms of service.
  - `frontend/styles.css`: Stylesheet.
  - `frontend/app.js`: Application logic.
